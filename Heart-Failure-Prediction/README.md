Heart Failure Prediction

Project Overview

This project predicts the possibility of heart failure using Machine Learning algorithms.

Objective

To analyze patient health data and predict the risk of heart failure.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- AdaBoost
- XGBoost

Machine Learning Algorithms

- AdaBoost Classifier
- XGBoost Classifier

Conclusion

This project helps analyze health data and predict the risk of heart failure using Machine Learning techniques.
